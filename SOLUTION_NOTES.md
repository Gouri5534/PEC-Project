# Enhancement notes

This archive contains the original participant-facing challenge dataset plus a locally runnable deterministic parser, a structural output validator, and honest evaluation/usage reports. The root `output.csv` is generated by `python code/main.py`.

The solution is an enhanced baseline, not a claim of high hidden-test accuracy. The public sample comparison showed low status agreement during development; see `code/evaluation/evaluation_report.md`. The output validator verifies format and contract constraints, not the correctness of each semantic decision. Review and improve the evidence-resolution logic before treating the CSV as a final competition submission.
